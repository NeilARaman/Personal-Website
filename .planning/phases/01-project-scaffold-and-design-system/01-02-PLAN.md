<task type="auto">
  <name>Task 1: Download font files and configure Astro Fonts API</name>
  <files>src/assets/fonts/InterVariable.woff2, src/assets/fonts/Lora-Variable.woff2, src/assets/fonts/Lora-Italic-Variable.woff2, astro.config.mjs</files>
  <action>
1. Create `src/assets/fonts/` directory
2. Download self-hosted .woff2 variable font files:
   - Inter Variable (regular, weight range 400-600): Get from fontsource or Google Fonts API. The file should be named `InterVariable.woff2`.
   - Lora Variable (regular, weight range 400-700): Named `Lora-Variable.woff2`
   - Lora Variable Italic (weight range 400-700): Named `Lora-Italic-Variable.woff2`
   
   Download approach: Install `@fontsource-variable/inter` and `@fontsource-variable/lora` temporarily, copy the .woff2 files from `node_modules/@fontsource-variable/*/files/` into `src/assets/fonts/`, then uninstall the packages. Alternatively, download directly from the fontsource CDN URLs.

3. Update `astro.config.mjs` to configure the Fonts API with local provider:
   ```javascript
   import { defineConfig, fontProviders } from 'astro/config';

   export default defineConfig({
     site: 'https://neilraman.com',
     fonts: [
       {
         provider: fontProviders.local(),
         name: 'Lora Variable',
         cssVariable: '--font-lora',
         options: {
           variants: [
             {
               src: ['./src/assets/fonts/Lora-Variable.woff2'],
               weight: '400 700',
               style: 'normal',
             },
             {
               src: ['./src/assets/fonts/Lora-Italic-Variable.woff2'],
               weight: '400 700',
               style: 'italic',
             },
           ],
         },
       },
       {
         provider: fontProviders.local(),
         name: 'Inter Variable',
         cssVariable: '--font-inter',
         options: {
           variants: [
             {
               src: ['./src/assets/fonts/InterVariable.woff2'],
               weight: '400 600',
               style: 'normal',
             },
           ],
         },
       },
     ],
   });
   ```

   NOTE: The Astro Fonts API is new in Astro 6. If the import path `fontProviders` from `astro/config` does not work, check the Astro 6 docs. If the Fonts API proves problematic, fall back to manual @font-face declarations in a `src/styles/fonts.css` file (see RESEARCH.md fallback pattern). The key requirement is self-hosted fonts loading correctly -- the method is Claude's discretion.

4. Run `npm run build` to verify fonts are processed correctly
5. Commit: "feat(01-02): add self-hosted fonts and Astro Fonts API config"
